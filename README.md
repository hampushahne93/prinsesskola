# Prinsesskola 👑

Ett klä-på-spel för små prinsessor och prinsar.

## Kungliga klädskåpet

Välj tjej eller kille och klä din figur i kungliga kläder: klänningar och dräkter, kronor, frisyrer, mantlar, skor, smycken och saker att hålla i. Byt färger, välj plats (slottet, balsalen, trädgården, stjärnnatten, regnbågen) och tryck **✨ Klar!** för att visa upp resultatet.

- Allt styrs med stora knappar och bilder, inget behöver läsas.
- En svensk röst säger vad man har valt (använder enhetens inbyggda talsyntes).
- 🎲 klär figuren slumpmässigt.

## Spela

Öppna `index.html` i en webbläsare. Allt ligger i den filen.
